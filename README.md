## Flicker — скрипт для автосдачи квестов на сервере GribLand

**EXE-файл:**

- находится в папке `/dist`
    
- ссылка: [https://drive.google.com/file/d/1q7CrZsuYiC0IOi_rnY19DNsrSrWBJok3/view?usp=sharing](https://drive.google.com/file/d/1q7CrZsuYiC0IOi_rnY19DNsrSrWBJok3/view?usp=sharing)
    

**Возможности:**

- Изменение координат для разных разрешений экрана.
    
- Полная настройка в файле `settings.ini`.
    

**Для чего нужен:**

- Быстрая сдача квестов для получения звания «Непобедимый».
    
- Исключение рутинной ручной работы.
    

---

### Настройка

Сначала выполните **выравнивание** (иногда GribLand блокирует макросы, поэтому важно правильно задать привязку).

1. Зайдите в меню квестов и нажмите на первый квест.
    
2. Наведите курсор на иконку квеста — это будут **начальные координаты**. Нажмите клавишу для записи начальной позиции (задаётся в начале программы).
    
3. Затем нажмите на иконку, после чего наведитесь на кнопку **«Подтвердить»** и запишите **конечные координаты**.
    
4. Все координаты сохраняются по горячим клавишам, указанным в интерфейсе программы.  
    Настройка завершена.
    

**Выравнивание** необходимо, чтобы курсор точно попадал на квест и скрипт работал корректно. После настройки можно запускать программу и наслаждаться её работой.

---

### Важно

- Программа требует прав администратора для корректного перехвата нажатий между окнами.
    
- Иногда программа может перестать перехватывать нажатия во время работы — в этом случае помогает только перезагрузка.
    
- Макросы запрещены правилами GribLand, вся ответственность за их использование лежит на вас.
    

---

### Структура файла `settings.ini`

ini

[SETTINGS]
time = 0.05          ; время задержки после каждой операции (в секундах)
start_stop = 1       ; клавиша для запуска / остановки
position1 = 8        ; клавиша для записи начальной позиции
position2 = 9        ; клавиша для записи конечной позиции
stop = f7            ; клавиша экстренной остановки
alignment = 2        ; клавиша для выравнивания
[POSITION1]
x = 0                ; координата X начальной позиции
y = 0                ; координата Y начальной позиции
count = 2            ; количество кликов
[POSITION2]
x = 0                ; координата X конечной позиции
y = 0                ; координата Y конечной позиции
count = 1            ; количество кликов

## Flicker - скрипт для автосдачи квестов на сервере GribLand

exe файл:
- В папке /dist
- https://drive.google.com/file/d/1q7CrZsuYiC0IOi_rnY19DNsrSrWBJok3/view?usp=sharing

Его возможности:
- Изменение кординат для разных разрешений
- Полная настройка в файле settings.ini

Для чего он нужен:
- Быстрая сдача квестов для Непобедимого
- Убрать ручную работу

Сначала выранивание, иногда GribLand блокирует макросы.
Зайдите в квесты и нажми на первый квест и наведитесь на иконку - это будет начальные кординаты. Нажмите на иконку и далее навидитесь на ```Подтвердить``` запиши конечные кординаты, все кординаты записываються по горячим клавишам которые указаны в начале программы. Настройка закончина.

Выравнивание нужно что бы навестись на квест и он стоял ровно для работы программы. можно запустить на наслождаться работой. 

Важно: программа требует права админестратора что бы коррекно перехватывать нажатия между окнами. Иногда программа перестанет перехватывать нажатие во время работы, тут только помжет перезагрузка. Макросы запрещены для GribLand, вся ответственность только на вас.

Строение settings.ini: 
[SETTINGS]
- time = 0.05 // время после каждой операции
- start_stop = 1 // кнопка для запуска/остановки
- position1 = 8 // кнопка для настройки начальной позиции
- position2 = 9 // кнопка для настройки конечно позиции
- stop = f7 // экстренная остановка
- alignment = 2 // для выравнивание

[POSITION1]
- // кординаты
- x = 0
- y = 0
- count = 2 // количество нажатий

[POSITION2]
- // кординаты
- x = 0
- y = 0
- count = 1 // количество нажатий
